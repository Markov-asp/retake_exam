# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),

## [1.0.0] — 2026-11-21

Первая публичная версия сервиса.

### Добавлено

- Загрузка Excel-отчётов через веб-интерфейс и `POST /api/reports`, включая
  перетаскивание файла и ограничение размера.
- Потоковый парсер `.xlsx`/`.xlsm` с автопоиском строки заголовков и разбором
  листов «Детали» и «Трекеры».
- Нормализация заголовков, чисел, дат и длительностей; восстановление даты из
  имени файла, FPS из кадров/длительности, `avg_hz` из точек/длительности.
- Хранение в SQLite: таблицы `reports`, `details`, `trackers`, индексы по датам
  и категориям, каскадное удаление, дедупликация по SHA-256.
- Агрегации по дням, месяцам и всему объёму (avg/sum/min/max) на стороне SQL.
- Дашборд с 26 графиками Plotly (14 + 12) и 8 KPI-карточками.
- Режим «весь объём»: гистограммы распределения и рейтинги категорий.
- Фильтры по периоду и отчёту, поиск, сортировка, пагинация таблицы.
- Экспорт выборки в CSV (UTF-8 BOM, `;`) и XLSX.
- Тёмная тема, адаптивная вёрстка, офлайн-Plotly, ссылки на состояние дашборда.
- REST API с OpenAPI/Swagger, единый формат ошибок, `X-Process-Time-Ms`.
- TTL/LRU-кэш агрегатов со сбросом при изменении отчётов.
- Демонстрационный отчёт на 36 съёмочных дней и генератор `scripts/generate_demo_report.py`.
- Документация: архитектура, API, модель данных, метрики, руководство пользователя.
- 78 автотестов pytest и конфигурация GitHub Actions (Python 3.10–3.13, ruff).

### Структура

- Код приведён к учебному шаблону: `src/` (`main.py`, `components/`, `services/`,
  `utils/`, `styles/`), `tests/`, `docs/` со скриншотами и `demo.mp4`, `.agent/`
  с журналом промптов, ошибок и конфигурацией.
- Добавлены `PROMPTS.md` и `REFLECTION.md`.

### Технические решения

- Один процесс: FastAPI + Uvicorn, SQLite, статика без сборки — запуск одной командой.
- Plotly-фигуры собираются на сервере и передаются клиенту как JSON.
- Каталог метрик (`src/services/catalog.py`) управляет парсингом, API и графиками.
- Для метрик частот нулевые значения исключаются из агрегатов (`positive_only`).
