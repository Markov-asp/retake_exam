## 3. Как строятся графики

### Числовая метрика, детализация «день» / «месяц»

```
столбец            — выбранная агрегация (avg/sum/min/max)
усы                — минимум и максимум внутри периода (только для avg)
пунктирная линия   — количество эпизодов в периоде, правая ось
наведение          — точное значение и подпись периода
```

Если в периоде одна запись, усы не рисуются.

### Числовая метрика, «весь объём»

Строится гистограмма распределения: границы корзин считаются по `min`/`max`,
количество корзин — от 5 до 60 (по умолчанию 20). Пунктиром показано среднее.
Корзины считаются в SQL (`CAST((value - min) / width AS INTEGER)`), поэтому
не требуют выгрузки всех строк в память.

### Категориальная метрика

- «день»/«месяц» — стековые столбцы: категория × период;
- «весь объём» — горизонтальный рейтинг, отсортированный по количеству.

Показываются 8 самых частых категорий, остальные объединяются в «Другие (N)».

### Оформление

- палитра из 10 цветов, одинаковая для легенды и столбцов;
- темы `light` и `dark` — разные цвета текста, сетки и столбцов;
- высота 340–560 px, адаптивная ширина, экспорт PNG из меню графика;
- `hovertemplate` с подписями на русском.

## 4. KPI-карточки

| KPI | Формула | Комментарий |
|-----|---------|-------------|
| Эпизодов | `COUNT(*)` по `details` | в подписи — число файлов трекинга |
| Дней наблюдения | `COUNT(DISTINCT date)` | минимальная и максимальная дата в подписи |
| Суммарная длительность | `SUM(duration_sec) / 3600` | часы, в подписи — секунды |
| Средний FPS | `AVG(fps)` | фактические значения |
| Средний битрейт | `AVG(bitrate)` | Мбит/с |
| Проблемные эпизоды | `COUNT(bad_intervals > 0) / COUNT(*) * 100` | % эпизодов с нарушениями |
| Средняя частота трекинга | `AVG(avg_hz) WHERE avg_hz > 0` | битые файлы не занижают среднее |
| Равномерность трекинга | `AVG(uniformity) WHERE uniformity > 0` | в подписи — суммарные пропуски |

Все KPI учитывают активные фильтры (период, отчёт).

## 5. Нулевые значения

Для метрик `points`, `avg_hz`, `start_hz`, `mid_hz`, `end_hz`, `uniformity`
ноль означает «файл не прочитан», а не физическое значение. В каталоге они
помечены `positive_only=True`, и агрегации исключают нули:

- средняя частота не падает с 90 до 87 Гц из-за трёх битых файлов;
- гистограмма не показывает ложный пик в нуле;
- сами записи остаются в таблице и в категории «Не прочитан / битый».

## 6. Категории качества

Исходный отчёт использует категории:

- видео: «Идеально 30 fps», «25 fps», «~30 fps, редкие пропуски», «Другой fps», «Битый файл»;
- трекинг: «Идеально ~90 Гц», «Не прочитан / битый».

Сервис не пересчитывает категорию — он показывает распределение так, как его
разметил конвейер, но дополнительно считает объективные метрики (FPS, доля
«плохих» интервалов, разрывы), по которым категорию можно проверить.
