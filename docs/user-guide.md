# Руководство пользователя

## 1. Запуск

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux/macOS

pip install -r requirements.txt
python -m src.main
```

Откройте <http://127.0.0.1:8000>. Порт можно изменить: `python -m src.main --port 8080`.

При первом запуске создаётся база `data/app.db` и импортируются отчёты из
`data/raw/`. Если каталог пуст, дашборд покажет приглашение загрузить файл.

## 2. Загрузка отчёта

1. Нажмите **«Загрузить отчёт»** в правом верхнем углу.
2. Перетащите `.xlsx`/`.xlsm` в пунктирную область или выберите файл.
3. При желании укажите название — оно отобразится в списке отчётов.
4. Нажмите **«Загрузить и обработать»**.

Что происходит дальше:

- файл проверяется на расширение и размер (по умолчанию до 256 МБ);
- сервис ищет листы «Детали» и «Трекеры», строку заголовков и нормализует строки;
- повторная загрузка того же файла распознаётся по SHA-256 и не создаёт дубль;
- после обработки дашборд открывается на новом отчёте.

Требования к файлу: лист «Детали» и/или «Трекеры», шапка в первых 15 строках,
одна строка — один эпизод. Неизвестные колонки не теряются, а сохраняются
в служебном JSON и участвуют в поиске.

## 3. Дашборд

### Вкладки листов

«Детали» — технические характеристики видео, «Трекеры» — телеметрия.
Переключение вкладки перестраивает KPI и все графики под выбранный лист.

### KPI

Восемь карточек над графиками: эпизоды, дни наблюдения, суммарная длительность,
средний FPS, битрейт, доля проблемных эпизодов, средняя частота и равномерность
трекинга. Карточки учитывают фильтры.

### Фильтры

| Элемент | Что делает |
|---------|------------|
| **Период с / по** | ограничивает выборку датами съёмки |
| **Детализация** | «По дням», «По месяцам», «Весь объём» |
| **Агрегация** | среднее, сумма, минимум, максимум для числовых метрик |
| **Селектор отчёта** | все отчёты вместе или один конкретный |
| **Сбросить** | возвращает период, отчёт, детализацию и агрегацию по умолчанию |

### Графики

Каждая карточка — одна метрика. Заголовок и подпись показывают сводку:
среднее/сумму, минимум, максимум и количество эпизодов.

- **столбцы** — значение метрики за период;
- **усы** — разброс min–max внутри периода;
- **пунктир** — количество эпизодов (правая ось);
- **«Весь объём»** — гистограмма распределения и линия среднего;
- **категории** — стековые столбцы по периодам или рейтинг категорий.

Наведите курсор на столбец, чтобы увидеть точные значения. Кнопка камеры в
правом верхнем углу графика сохраняет PNG.

### Таблица

Под графиками — таблица нормализованных записей:

- поиск по всем значениям, включая кириллицу и неизвестные колонки;
- сортировка кликом по заголовку (повторный клик меняет направление);
- пагинация по 25 записей;
- **CSV** и **Excel** экспортируют текущую выборку с учётом фильтров и поиска.

Таблица прокручивается по горизонтали: в отчёте 19 колонок.

## 4. Отчёты

Раздел **«Отчёты»** показывает карточки загруженных файлов: количество строк,
пропущенные строки, дату загрузки и статус.

- **Показать** — открыть дашборд только по этому отчёту;
- **Скачать** — исходный `.xlsx`;
- **Удалить** — удалить отчёт вместе со строками (необратимо).

Отчёты не смешиваются в базе: каждый хранится отдельно, а селектор «Все отчёты»
позволяет смотреть агрегат по нескольким выгрузкам.

## 5. Тема и ссылки

Кнопка с месяцем переключает светлую и тёмную тему; выбор запоминается в браузере.

Состояние дашборда можно передать ссылкой:

```
http://127.0.0.1:8000/?sheet=trackers&granularity=month&theme=dark
http://127.0.0.1:8000/?view=reports
```

Параметры: `sheet`, `granularity`, `aggregation`, `theme`, `view`.

## 6. Типичные ситуации

| Симптом | Причина и решение |
|---------|-------------------|
| Дашборд пуст, видно приглашение загрузить файл | в базе нет отчётов — загрузите `.xlsx` |
| «Нет данных по выбранным фильтрам» | период не пересекается с датами отчёта — нажмите «Сбросить» |
| Ошибка «В файле не найдены листы „Детали“ или „Трекеры“» | переименуйте листы или проверьте, что это нужный отчёт |
| Ошибка «Не удалось найти строку заголовка» | шапка находится ниже 15-й строки или содержит меньше двух известных колонок |
| `422` при загрузке | расширение не `.xlsx`/`.xlsm`, файл повреждён или превышен лимит |
| Порт занят | `python -m src.main --port 8080` |
| Тесно в таблице | прокрутите таблицу по горизонтали или выгрузите CSV |
| Данные не обновились | обновите страницу; кэш сбрасывается при загрузке/удалении отчёта |

## 7. Горячие клавиши

- `Esc` — закрыть окно загрузки;
- `Enter`/`Space` в зоне загрузки — открыть выбор файла.
