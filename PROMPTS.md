Проект разрабатывался в диалоге с агентом DeepSeek Harness. Ниже — хронология

## 1. Исходная постановка

**Дата:** 21.11.2026, 21:44
**Промпт (дословно):**

> Привет!
> Необходимо реализовать Сервис обработки и визуализации данных (дашборды, отчёты).
>
> 1. Сервис должен работать с большими объемами данных с отчетов, в которых включены
> технические характеристики видео и трекинг файлов. Сервису также необходимо строить
> информативные графики по каждой метрике (столбцы) на листах "Детали" и "Трекеры",
> чтобы вести учет данных по дням, месяцам, на всем объеме
>
> В корневую директорию проекта прикрепил пример отчета для обработки и дальнейшей
> визуализации ( @data_detail-report.xlsx )
>
> 2. Придерживайся структуры проекта, указанной на скриншоте и обязательно создай все
> необходимые файлы о проекте и твоей работы. Все указано на скриншоте
>
> 3. Проект в дальнейшем будет залит на GitHub для получения зачета по экзамену

**Что было в промпте сильно:** чётко назван тип проекта, перечислены разрезы
(день/месяц/весь объём), приложен реальный файл, указан критерий приёмки —
публикация на GitHub.

**Что было слабо:** скриншот структуры не прикрепился, поэтому требование
«придерживайся структуры» нельзя было выполнить буквально. Агент это заметил
и задал уточняющий вопрос вместо догадок.

## 3. Первая версия сервиса

**Дата:** 21.11.2026, 21:57–22:20

Промптов на этом этапе не было — агент работал по исходной постановке. Ключевые
решения, принятые без дополнительных вопросов:

- потоковый парсер `openpyxl` вместо загрузки книги целиком;
- SQLite + SQL-агрегации вместо pandas-пересчётов;
- каталог метрик как единственный источник правды;
- 26 графиков (14 + 12) и 8 KPI;
- серверный Plotly JSON + вендорный `plotly.js` (работает офлайн);
- 78 тестов и CI.

**Результат:** рабочий сервис, скриншоты, документация, зелёные тесты.

## 4. Правка структуры по скриншоту

**Дата:** 21.11.2026, 22:37
**Промпт (дословно):**

> [изображение со структурой проекта]
> Сверь с этой структурой пожалуйста

На скриншоте был шаблон учебного проекта:

```
README.md, PROMPTS.md, REFLECTION.md, .gitignore, requirements.txt
src/ (main.py, components/, services/, utils/, styles/)
tests/, docs/ (screenshots/, architecture.md, demo.mp4)
.agent/ (prompt-log.md, errors.md, config.json)
```

**Что сделал агент:**

1. Сверил дерево и составил список расхождений: нет `src/`, `PROMPTS.md`,
   `REFLECTION.md`, `.agent/`, `docs/demo.mp4`.
2. Перенёс `app/` → `src/`: `core → utils`, `db → services`,
   `web/templates + js → components`, `css → styles`.
3. Обновил импорты, `pyproject.toml`, CI, Makefile, тесты и документацию.
4. Добавил точку входа `src/main.py` (`python -m src.main`).
5. Создал артефакты работы с ИИ и видео-демонстрацию.

**Промпт-урок:** если структура критична для приёмки, её нужно прикладывать
к первому сообщению или явно писать «структура будет позже, начни с анализа».
Один отсутствующий скриншот стоил полной перекладки каталогов.
